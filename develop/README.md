## Структура тестов

| Метод | Что проверяется |
|---|---|
| `add_new_book` | Валидные имена (параметризация, граница 40 символов), невалидные (пустое имя / 41 символ), запрет дубликата |
| `set_book_genre` | Успешная установка жанра; параметризация невалидных данных (книги нет в словаре / жанра нет в списке доступных) |
| `get_book_genre` | Возврат жанра книги; `None` для неизвестной книги |
| `get_books_with_specific_genre` | Список книг нужного жанра |
| `get_books_genre` | Проверяется внутри тестов `add_new_book` (словарь) |
| `get_books_for_children` | Книги с возрастным рейтингом исключены; книга без жанра не попадает в список |
| `add_book_in_favorites` | Успешное добавление, запрет дубликата (параметризация), игнор несуществующей книги |
| `delete_book_from_favorites` | Удаление существующей книги; безопасный вызов для отсутствующей |
| `get_list_of_favorites_books` | Проверяется в тестах избранного |# qa_python
